# A12 – Glossar

| Begriff | Bedeutung |
|---|---|
| WG | Wohngemeinschaft, die eine gemeinsame Einkaufsliste und Kostenverwaltung nutzt. |
| Membership | Zuordnung eines Users zu einer WG mit Rolle und Beitrittszeitpunkt. |
| Admin | Mitgliedsrolle des WG-Erstellers mit erweiterten Verwaltungsrechten innerhalb der Wohngemeinschaft. |
| Member | Standardrolle eines Mitglieds innerhalb einer Wohngemeinschaft. |
| Invite-Code | Sechsstelliger, eindeutiger Code zum Beitritt zu einer WG. |
| ShoppingItem | Fachliches Datenobjekt zur Verwaltung eines Einkaufsartikels innerhalb einer WG. |
| Expense | Erfasste gemeinsame Ausgabe. |
| ExpenseShare | Kostenanteil eines Mitglieds an einer Ausgabe. |
| Debt | Aus einer Kostenaufteilung resultierende Forderung zwischen zwei Mitgliedern. |
| Saldo | Berechnete Differenz zwischen bezahlten Ausgaben und eigenen Kostenanteilen. |
| `open` | Technischer Status für einen offenen Artikel oder eine offene Schuld. |
| `bought` | Technischer Status eines gekauften Artikels. |
| `paid` | Technischer Status einer beglichenen Schuld. |
| Offline-Persistenz | Lokales Vorhalten und späteres Synchronisieren bereits geladener Daten. |
| Firestore Security Rules | Regeln zur Prüfung von Lese- und Schreibberechtigungen in Firestore. |
