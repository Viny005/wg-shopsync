# E2 – Glossar

| Begriff | Beschreibung |
|----------|----------|
| Benutzer | Registrierter Nutzer der Anwendung WG‑ShopSync. Ein Benutzer kann Mitglied einer Wohngemeinschaft sein und innerhalb dieser WG eine bestimmte Rolle besitzen. |
| WG | Wohngemeinschaft, deren Mitglieder gemeinsame Einkaufslisten und Ausgaben verwalten. |
| Invite-Code | Eindeutiger Code zum Beitritt zu einer WG. |
| Membership | Zugehörigkeit eines Benutzers zu einer bestimmten WG. |
| Einkaufsliste | Gemeinsame Liste von Einkaufsartikeln einer WG. |
| Artikelkategorie | Fachliche Einordnung eines Einkaufsartikels zur besseren Strukturierung der Einkaufsliste (z. B. Lebensmittel, Getränke, Haushalt oder Hygiene). |
| Ausgabe | Von einem Mitglied erfasste gemeinsame Kosten. |
| Käufer (Buyer) | Mitglied, das eine Ausgabe zunächst bezahlt hat. |
| Saldo | Berechnete Differenz zwischen Ausgaben und Kostenanteilen eines Mitglieds. |
| Synchronisation | Abgleich lokaler und serverseitiger Daten. |
| Offline-Modus | Nutzung der Anwendung ohne aktive Internetverbindung. |
| HTTPS | Verschlüsselte Kommunikation zwischen Anwendung und Server. |
| Passwort-Hash | Verschlüsselte Darstellung eines Passworts zur sicheren Speicherung. |
